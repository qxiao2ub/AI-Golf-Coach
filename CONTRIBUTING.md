# Contributing

Contributions should preserve the project's educational scope and responsible-use boundaries.

1. Create a branch.
2. Add or update tests for behavior changes.
3. Run `python -m pytest -q`.
4. Run the app locally with `streamlit run streamlit_app.py`.
5. Do not add personal videos, health information, secrets, or unlicensed training data.
6. Clearly label synthetic data and unvalidated metrics.
