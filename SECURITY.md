# Privacy and Security Notes

- Do not commit uploaded videos, names, health notes, API keys, or other personal data to GitHub.
- The Streamlit app processes uploaded files inside the active cloud session and does not intentionally persist them to the repository.
- Streamlit Community Cloud instances and local temporary directories should not be treated as regulated-data storage.
- Do not use CUI, FOUO, ITAR, EAR, PII, PHI, medical records, or other controlled/sensitive data with this educational prototype.
- Before production use, add authentication, encrypted storage, retention/deletion controls, access logging, consent records, and a formal privacy review.
